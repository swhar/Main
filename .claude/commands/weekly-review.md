# /weekly-review — End-of-Week Review & Reset

Run at the end of each week (typically Friday afternoon or Sunday evening) to close out the week and set up the next one.

## Steps

1. Read `memory/profile.md` for current goals and focus areas.
2. Read `memory/tasks.md` to see what was completed, in progress, or untouched this week.
3. Read `memory/decisions.md` and `memory/learnings.md` (last 7 days only) to surface what shifted.
4. Skim each active file in `projects/` for a one-line status delta.
5. Walk the Weekly Review prompts from `prompts/elite-techniques.md` (Planning Frameworks → Weekly Review).
6. Ask the user any gap questions before producing output (e.g., "What drained you this week?", "Anything you want to stop doing?").
7. Produce a structured review in this format:

---

## Weekly Review — Week ending 2026-05-07

**Completed**
- [Item — project/goal it served]
- [Item — project/goal it served]

**Didn't get done (and why)**
- [Item — root cause: priority? blocker? energy?]

**Wins to bank**
- [Tangible or intangible — momentum, relationship, insight]

**Drag points**
- [What slowed you down or recurred as friction]

**Next week's single most important thing**
> [One sentence — the keystone outcome that would make next week a success]

**Stop doing**
- [Behavior, meeting, or task to drop]

**Memory updates suggested**
- Profile: [any goal/focus shift to consider]
- Learnings: [the one insight worth keeping]
- Tasks: [items to roll forward, defer, or kill]

---

8. Offer to save the keystone insight and any goal shifts via `/remember`.
9. Ask: "Want to run `/plan-day` for Monday now, or set the keystone outcome aside until then?"
