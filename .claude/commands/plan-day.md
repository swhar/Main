# /plan-day — Daily Planning Workflow

Builds a prioritized, realistic, time-blocked plan for the day.

## Steps

1. Read `memory/tasks.md` for current tasks and priorities.
2. Read `memory/profile.md` for working style preferences (e.g., deep work hours, energy patterns).
3. Ask: "How much time do you have today? Any fixed commitments or meetings I should plan around? How's your energy level (high / medium / low)?"
4. Apply the Eisenhower Matrix (from `prompts/elite-techniques.md`) to categorize tasks:
   - Urgent + Important → Do now
   - Not Urgent + Important → Schedule (protect time for these)
   - Urgent + Not Important → Batch or minimize
   - Not Urgent + Not Important → Drop from today
5. Build the plan in this format:

---

## Day Plan — [Date]

**Deep Work Block** (protect this time — no interruptions)
- [Time]: [Task] — Goal: [specific outcome]

**Action Block**
- [Time]: [Task] — [~X mins]
- [Time]: [Task] — [~X mins]

**Admin / Comms Block**
- [Time]: [emails, messages, small tasks]

**If Time Allows**
- [Lower-priority items that would be nice to do]

**End-of-Day Target**
> [What "done" looks like today — the one thing that makes today a success]

---

6. Ask: "Want to adjust anything before we lock this in?"
7. Offer to update `memory/tasks.md` with any status changes from the planning session.
