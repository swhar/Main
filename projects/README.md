# Projects

One `.md` file per active project. Claude reads the relevant file when you mention a project name.

## File naming
Use `project-name.md` — lowercase, hyphens for spaces.

## Template

Create each project file with this structure:

```markdown
# Project: [Name]

**Status:** [Active / On hold / Complete]
**Goal:** [What success looks like]
**Deadline:** [If applicable]

## Context
[Brief background — what this is and why it matters]

## Current State
[Where things stand right now]

## Next Steps
- [ ] [Next action]
- [ ] [Next action]

## Key Decisions
- [Decision made, with date]

## Notes / History
[Running log of updates, oldest to newest]
```
