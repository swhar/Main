# Knowledge

Research outputs, reference documents, and saved notes. Files here are created by `/research` and can also be added manually.

## File naming
Use descriptive names: `topic-name.md` or `YYYY-MM-DD-topic.md` for time-sensitive research.

## Usage
- Drop any document or note here and Claude can read it on demand
- Reference in chat: "Read knowledge/filename.md and summarize it"
- `/recall <topic>` will point you to relevant files here
