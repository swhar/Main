# Memory Archive

Long-term storage for memory entries that have rolled off active files. See `memory/MEMORY-CONVENTIONS.md` for the full rules.

---

## What lives here

### Weekly task rollups
**Filename:** `YYYY-Www.md` (ISO week, e.g. `2026-W19.md`)

Generated by the `/weekly-review` workflow. Captures:
- Completed tasks moved out of `tasks.md` → "Completed This Week"
- Title-only references to decisions and learnings logged that week (bodies stay in their primary files)
- Free-form weekly reflection notes

### Yearly decision/learning archives (only when triggered)
**Filename:** `decisions-YYYY.md`, `learnings-YYYY.md`

Created **only** when the active `decisions.md` or `learnings.md` exceeds the soft threshold defined in `MEMORY-CONVENTIONS.md` §3 (500 entries / 10K lines / >1 calendar year of entries). Until then, these files do not exist.

---

## What does NOT live here

- Active project files → `projects/`
- Research outputs and reference notes → `knowledge/`
- Anything still in active rotation → primary `memory/*.md` files

---

## Naming reference

| Pattern              | Example             | Cadence            |
|----------------------|---------------------|--------------------|
| `YYYY-Www.md`        | `2026-W19.md`       | Weekly             |
| `decisions-YYYY.md`  | `decisions-2025.md` | When triggered     |
| `learnings-YYYY.md`  | `learnings-2025.md` | When triggered     |

ISO week numbers: see `date +%G-W%V` on Linux/macOS, or the date displayed in `/briefing`.
